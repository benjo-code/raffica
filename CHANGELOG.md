# Changelog

All notable changes to this project are documented here.

Format after [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), versioning after [Semantic Versioning](https://semver.org/). Every release entry names the included milestones.

## [Unreleased]

### Added

- Raffica PDF viewer: open, tabs, scroll, zoom, search, links, print. Open files by argument, dialog or drag and drop (with a password prompt); a second file opens in the running instance; a file that is already open is selected. Tabs, continuous scroll, single, continuous and two-page layouts, zoom modes (page width, whole page, actual size, free up to 800 percent), go to page, a dark page without inverted images, a pages pane with thumbnails and an outline pane.
- Search with highlights, next and previous; select and copy text; links with a confirmation that shows the address before an external one opens; document info and the F1 help card; command palette entries for open tabs, recent files, pages and outline entries; keyboard shortcuts for every viewer action.
- Settings for PDF (page appearance, default layout and zoom, print scaling); position per file (except a file given on the command line at first launch); printing on Windows (system print dialog) and Linux (CUPS) with page range, copies, fit to paper and a background job with progress and cancel. English and German.
- Raffica PDF annotating and saving: markup (highlight, underline, strike-through) with comments, freehand, rectangle, ellipse, line, arrow and text box tools, select, move, resize and delete, and one undo and redo history for all of them; a colour and width strip, a marks pane that lists every mark with its comment, save and save as (incremental by default, atomic and checked) with a warning for signed files, failure cards, and an unsaved-changes prompt on close. English and German.
- Raffica PDF forms and signing: fill a form by clicking its fields (text, check box, radio button, list and combo box), with Tab and Shift+Tab walking the fields, a switch that highlights the fields, a counter of empty required fields with a card before saving, and a note for what is not supported (calculations, XFA, buttons). Add a visible signature, drawn or imported from an image, from up to ten saved signatures; it is a picture on the page, not a digital signature. A Forms ribbon tab holds the commands. English and German.
- Raffica PDF organizing pages: a Pages ribbon tab and an organize mode in the pages pane to reorder pages by drag or keys, rotate, delete, duplicate and add blank pages, and insert pages of other files (merge); nothing is written until Apply, which lists what a rewrite loses, warns for signed files and offers Save as or the original file. Split a file by a number of pages, by ranges or by bookmarks, extract pages into a new file and export pages as PNG images. Limits: at most 20 inserted files per organize session (leave the mode and enter it again to insert more), 20 000 pages per plan and 64 megapixels per exported image. English and German.
- Raffica PDF redacting, text recognition and editing text lines: a Redact tab to mark text by selection, area or search (also email, IBAN, phone and card patterns), with a fill colour, blur or pixelate for image parts and overlay text; pages that cannot be taken apart can be turned into an image. Nothing is written until Apply, which rewrites the file, checks the result for the removed text and lists what was checked and what was not (a search names the picture pages and explains how to make them searchable with text recognition first, it never recognizes silently). An Edit tab to recognize text in scans in the background (English and German bundled, more languages from a file on disk, Cancel at any time) and to correct a line of existing text, an empty text removes the line. English and German.
- Raffica PDF packages, default app, updates and About (Milestone 2.6): a per-user Windows installer (English and German, keeps your settings on uninstall) and a portable ZIP, a Linux `.deb` and an AppImage (built and smoke-tested in a container and in the release workflow dry run; not yet installed on a real Linux desktop). The Windows files are unsigned (SmartScreen shows a notice); the command line tool `raffica` is included. Raffica PDF registers for PDF files and asks at start whether to become the default PDF app, once per start, until you choose "Don't ask again" (also in Settings and the command palette; on Windows the system's "Default apps" page opens for your confirmation). Updates: at most one check every 24 hours against the release address compiled into the app, switchable under Settings, "Check for updates automatically"; the installer form and the AppImage install after a confirmation (unsaved changes are asked first, the tabs come back after the restart), the `.deb` and the portable ZIP only point to the download page; the signature of the release information and the size and SHA-256 of the file are checked. The About card shows version, license, project address and the notices of the third-party components (palette command "About Raffica PDF"; a component's notice opens when you expand it). No release is published yet, so no update is offered.
- Raffica PDF: an unexpected error no longer ends the app without a word. It is written to `crash.log` (time, error type, message and stack, never a file path or document text) and a card says to save under a new name and restart, with a button for the folder; an error loop still ends the app.

- Raffica PDF: the window now fits the work area of a small screen (never taller than the screen less a margin) and opens where it was when you closed it, maximized or not; a position on a screen that is gone moves back inside.
- Raffica PDF: files opened from the file manager while the app is still starting are taken over by the running window (it listens as soon as it is open), and a file that arrives while a card or the close question is open waits until the card is gone instead of switching the tab under it; a close that finds another card open now asks its question after that card instead of silently refusing to close.
- Raffica PDF: dropping or opening many files that cannot be opened shows one card with the first five names and "and N more" instead of one card per file, and a recent file that cannot be read for now (an offline share, a damaged file) stays in the list; only a file that is gone leaves it.
- Raffica PDF: after an update restarts the app, the tab that was active is active again instead of the last one.
- Raffica PDF: scrolling to the end of a document (End key, scroll bar) now shows the last page in the status bar, also when many short pages share the last screen.

### Changed

- Raffica PDF: every command in the ribbon and the compact bar now has an icon of its own (printer, folder, save, scissors, highlighter and so on) instead of eight commands sharing one arrow.
- Raffica PDF: the app icon is now the Raffica PDF mark (plum square with `Pd` and wind streaks) in the installer, on the exe and in the Linux packages, replacing the placeholder.
- Raffica PDF: faster start on Windows and a third of the idle memory through software rendering; set `RAFFICA_RENDERING=default` to use the GPU path instead.
- Raffica PDF: the ribbon no longer clips commands in a narrow window. Below the width the full band of a tab needs (at the default window width, for example, the Home and Pages tabs) the command bar switches to the compact layout by itself, and when even that does not fit it scrolls with an arrow button at each end; Tab moves the focus into view. The setting "Compact command bar" still forces the compact layout at any width.
- Raffica PDF: a ribbon label breaks only at a space or hyphen and never in the middle of a word, and the German names are shorter ("Anmerken", "Änderungen anwenden", "Felder hervorheben", "Rückgängig", "Wiederholen", "Verwerfen", "Als Bilder exportieren …", "Aus Datei einfügen …").
- Raffica PDF: the View tab buttons now show what is on: the zoom fit mode (page width, whole page, actual size), the page layout, the dark page and the pane that is open are drawn pressed, and assistive technology reads them as switches that are on or off; the ribbon tabs report which one is selected.
- Raffica PDF: the group names of the ribbon now sit on one row in every group, the key tips (Alt) of the commands sit over the icon of a large button or beside a small one instead of covering text, with the long wording of shortened German names in the tooltip and the search, the zoom buttons and slider of the status bar have tooltips, scrolling the ribbon works with a horizontal wheel too, and the search results no longer list an entry twice that is also a ribbon command.
- Raffica PDF: the Help group of the Home tab now also holds "Document info" and "Check for updates"; the close button of the form notice can be reached with the keyboard and Esc closes the notice; the two-page-with-cover layout and the find bar previous and next buttons have their own icons.

### Fixed

- Raffica PDF: "Done" (Annotate) and "Stop editing" (Edit) no longer use a check mark, which read like a switched-on option when the command was dimmed; they show a leave arrow and a return arrow.
- Raffica PDF: long key descriptions in the shortcut list (F1) wrap onto a second line instead of ending in an ellipsis (German "Seiten organisieren: markierte Seiten um eine Stelle verschieben"), and the list uses the full width of the card.
- Raffica PDF: the list of all open documents (the arrow next to the tabs, shown when many tabs are open) is no longer empty in the release build; it names every tab and marks the current one.
- Raffica PDF: the window no longer gets taller by the height of the title bar (30 px) at every start on Windows; it opens at the size it was closed with.
- Raffica PDF: "Not now" on the card that offers to make Raffica the default PDF app is remembered for 30 days instead of asking at every start; "Don't ask again" still stays permanent.
- Raffica PDF on Windows: an installation for all users is recognized as registered for PDF files, so the app no longer asks to be made the default again and writes no second registration for your account.
- Raffica PDF on Linux: an `APPIMAGE` variable inherited from another program no longer points the desktop file at a foreign AppImage; it counts only while Raffica itself runs from inside that AppImage.
- Raffica PDF: the language files command is locked while a text recognition runs in any tab, not only in the active one.
- Raffica PDF: with many open files the tabs no longer cut the file name in the middle of ".pdf": the name is shortened before its extension and the extension goes first when there is little room; when the tabs do not fit, arrows scroll the strip, a list button names every open document and selects the one you click, and assistive technology knows which tabs are out of view. The language cell of the status bar takes no room while it is empty, and a dialog in a very small window keeps room for a few rows instead of shrinking to a sliver.
- Raffica PDF: in German the check boxes, buttons and toggles of the redact pane and its Find panel (256 px wide) break their labels into lines instead of cutting them off (for example "Textgröße an die Markierung anpassen"), and the text box for the text on the marks has the short hint "Optionaler Text" / "Optional text".
- Raffica PDF: the About card fits its card (the notices list is no longer wider than the card, the intro wraps), the component rows open and close like a disclosure instead of turning pink, each row names the component and its licence, the project address is a link that asks before it opens, and the German notice text says "enthält" with its umlaut.
- Raffica PDF: screen readers now find the page view as a document named "<file>, page 3 of 12" (it follows the current page, in English and German) and the status bar cells (save state, position, page count, zoom value) with their text.
- Raffica PDF: cards and dialogs scroll when the window is small or the display scaling is large (Settings, for example, was cut off at 150% scaling): the card is never taller than the window less 48 px, its body scrolls and the focused control is brought into view with Tab.
- Raffica PDF: the status bar no longer cuts its cells: the save state says "Unsaved" ("Nicht gespeichert"), and the page count with its size ("128 pages · 210 × 297 mm") and the position ("Page 1000 of 1000") grow with their text, in English and German.
- Raffica PDF: the start view now shows one tile, "Open PDF" (the Write, Sheets and Slides tiles that did nothing are gone), and it and the "+" of the tab strip (now named "Open file") open the file picker. The search field in the title bar says "Search commands", and the palette offers "Search the document for ..." as its last result when a document is open.
- Raffica PDF redaction: a page that carries attached files (`/AF`, for example the XML of a PDF/A-3 invoice) or an article thread (`/B`, with its title and author) no longer keeps them silently: the file is refused like a page with a thumbnail, and the check of the written file also fails when an embedded file other than a paperclip note is left. The report lists "Attached files" as cleaned only after the written file was read back, and names sound, video and other media of annotations under "Not cleaned".
- Raffica PDF Extract pages and Split document: the confirm card now says what every new file keeps from the document level (attached files, scripts, form fields and bookmarks of other pages, each only when the document has them) and points to Redact for content that must not be passed on. The new files stay working PDFs.
- Raffica PDF: Save as, Apply (page organizer and redaction) with Save as and Extract pages no longer write onto a file that another tab has open (also under another spelling, link or short name): they say "<name> is open in another tab. Close it first." and write nothing, so two tabs can no longer end up with one path. Save in the close question now says that a save is already running instead of doing nothing.
- Raffica PDF: saving a file with more than 10,000 annotations in total no longer fails the check of the written file with "annotations instead of" on a page that was edited after other pages were listed.
- Raffica PDF: a date written with an offset that ends after the hours (`+01'`) is now read instead of being treated as missing.
- Raffica PDF: a link that jumps to a position on a page with a CropBox or a rotation now lands on that position instead of beside it.
- Raffica PDF: saving a file that is opened through a symbolic link now writes the file the link points to and keeps the link, instead of replacing the link by a copy.
- Raffica PDF: when Windows keeps the old file after a save that replaced a file in use (an old copy named `.pw-...old`), a card now names that path; for a redaction it says the unredacted original is still there and must be deleted.
- Raffica PDF text editing: a page of extreme size (a few billion points on one side) is refused with the note that the page cannot be rewritten, instead of asking for a picture of a billion pixels for the check.
- Raffica command line on Windows: text with umlauts and other non-ASCII characters now shows correctly in a console (redirected output stays UTF-8 as before).
- Raffica PDF forms: an editable combo box (a choice list that also takes your own text) can now be typed into; before, the field opened without a text box. A value that is already there is shown when the editor opens.
- Raffica PDF: the editing field of a text box and of a form field now always has white paper, a black caret and a dark edge and selection (3 : 1 or more on the paper) in every theme; in the dark and the high-contrast theme the caret and the edge were almost invisible.
- Raffica PDF and shell: the selected page or outline entry in the side pane now has a 2 px dark edge bar besides the tint (the tint alone was 1.2 : 1), and selected text in a text field now has a darker highlight (3 : 1 or more on the field) with light text on it in the light, dark and high-contrast theme.
- Raffica PDF forms: the lock mark of a read-only or unsupported field now sits outside the field, left of it (right of it when there is no room), instead of over the value.
- Raffica PDF in German: seven texts of the Apply and Export images cards (the file is rewritten, finish the open edit, the document could not be taken over, the plan changed, the resolution) no longer address you with "du"; the German UI now says "Sie" throughout, pinned by a test.
- Raffica PDF: a page selection now also accepts "alle" (besides "all"), the CLI too; in German the page range fields of Insert pages, Split document and Export images start with "alle" and the labels and hints name "alle" in quotes (they said "all" or, in one place, "alle" that the parser rejected).
- Raffica PDF wording: the German update texts now say "herunter" ("Laden Sie die neue Version von der Download-Seite herunter"), "Wie die Darstellung" replaces "Wie das Design", the redact cards say "annotations" (not "marks", which are the redaction marks there) for the marks of annotating, "Gehe zu" became "Zu Seite springen" (Sie-neutral), button and tab names are quoted the same way in both languages ("Apply" and „Anwenden“), the field highlight is called "Highlight fields" in English too, English uses US spelling (color, canceling, millimeters), "Schließen, ohne zu speichern?" has its comma, and every ellipsis is a single "…" directly after the word ("Aus Datei einfügen…").
- Raffica PDF cards and dialogs: every card now has its buttons in one order, the main action first, then the other actions, Cancel last, so Enter always means the main action and Esc the cancel (before, the order differed from card to card, for example Cancel came first on the signed-file question and in Settings). Enter now works anywhere in a card, not only on a button.
- Raffica PDF: a disabled command now says why when you hover it: "Turn on "Redact" first" for the Redact commands (the same for Organize pages, Edit text), "There are no changes to save", "Only one document is open", "Select pages first" and so on, and Print, Save and Save as say "A save is running" while a save runs.
- Raffica PDF: the keyboard shortcuts card (F1) now has a "Navigation" section for the keys that belong to no command: Ctrl+K for the search field, F6 between the panes, Alt for field codes, Ctrl+Y, Enter and Shift+Enter in the search field, the keys of Organize pages and of forms, Ctrl+Enter for text boxes and comments and Ctrl+Shift+G while editing text (written as Cmd on macOS and as Strg in German).
- Raffica PDF: the hints of the cards (a wrong page range, a wrong password, a wrong number of copies and the like) are now read out by a screen reader as soon as they appear, and Windows shows "Raffica PDF" instead of "RafficaPdf" as the name of the program (print dialog and queue, Task Manager); a print job is titled with the name of the document.
- Raffica PDF cards and dialogs: a held Enter key no longer presses a button again and again, and the German reason for Redo says "Es gibt nichts zu wiederholen" like the command.
