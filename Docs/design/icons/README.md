# App icons (placeholder)

The icons in this folder and `src/Raffica.Pdf/Assets/raffica-pdf.ico` are **placeholders**. Raffica has no brand mark yet. The placeholder is a rounded square in the accent colour of the PDF app (`Raffica.Color.Ink.Pdf`, `#5E1A3E`) with a plain geometric "R". It is not a logo and is not meant to become one. The artwork of Pagewing is not used.

Open item for the owner: draw the real mark and replace the files below before the first public release.

## What the packaging reads

| File | Used by |
| --- | --- |
| `src/Raffica.Pdf/Assets/raffica-pdf.ico` | the Windows installer (`SetupIconFile` in `packaging/windows/raffica-pdf.iss`, passed as `/DIconFile` by `tools/package.cs installer`) |
| `Docs/design/icons/linux/hicolor/<n>x<n>/apps/raffica-pdf.png` | the Debian package (`/usr/share/icons/hicolor`) and the AppImage (the 256x256 file is also the root icon); sizes 16, 24, 32, 48, 64, 128, 256 and 512 |

The `.ico` holds the sizes 16, 24, 32, 48, 64, 128 and 256 (PNG entries).

## How to replace them

1. Export the real mark as PNG in the sizes above (square, transparent background) and as one multi-size `.ico`.
2. Overwrite the files at the paths in the table. Keep the file names; `tools/package.cs` and the `.desktop` file (`Icon=raffica-pdf`) depend on them.
3. Delete `tools/make-placeholder-icon.cs`, or leave it only if the new files are still generated by it. It draws the placeholder deterministically and takes no packages: `dotnet run tools/make-placeholder-icon.cs`.
4. Run `dotnet run tools/package.cs -- selftest` and build the packages as described in `packaging/README.md`.
